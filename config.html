从哪里获取 Key
智谱（推荐 · 永久免费不限次）
  1. 手机或电脑浏览器打开 open.bigmodel.cn
  2. 右上角注册（手机号即可），完成后登录
  3. 进入「控制台」→ 左侧菜单找「API Keys」
  4. 点「创建 API Key」，名字随便填，确认
  5. 复制生成的一串字符（形如 xxxxx.xxxxx），粘贴到上面输入框
注意：Key 只显示一次，建议同时存到微信收藏。
硅基流动（备用 · 注册送 14 元）

  2. 控制台 → API 密钥 → 新建
