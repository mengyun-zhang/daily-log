# 生产日报系统 · 使用说明书

## 这是什么

一个装在手机上的网页版生产日报工具，帮你每天记录炉台数据，一键生成日报文字发给领导。不用装 App，手机浏览器打开网址就能用，数据存在自己手机里，不会传到别处。

系统一共有四个页面：**日志**（每天记数据）、**历史**（看以前记的）、**排班**（排白班夜班休息）、**配置**（设置人员和炉号）。

---

## 一、日志页（每天用）

打开后默认就是日志页，顶部显示今天的日期和班次。

### 顶部：日期和班次
- 日期是"年 月 日"格式，**"日"的数字是蓝色加粗**，方便一眼看清今天几号。
- 白班显示 ☀️，夜班显示 🌙（蓝色月亮），点"白班 / 夜班"按钮就能切换。
- 左边有「‹ 前一天」按钮，看或补记昨天、前天的数据用；不在今天时会多出「回到今天」按钮。

### 当班人员
- 一行名字按钮，点一下切换是否当班：**灰色 = 当班，白色 = 不计入**。
- 亷丽霞名字前有个 ❤️ 爱心标记，方便认人。

### 炉台运行数据（重点）
一张表，每一行是一个炉号，要填四样东西：
- **产量 kg**（必填的核心数据）
- **风量**
- **松装 kg**
- **比表 m²/g**

只填有生产的炉台就行，没填的炉号不会出现在日报里。比表超过 10 会自动标红提醒复核。

### 比表识别（省手填）
点「比表识别」按钮，弹出一个小框，把别人发给你的"炉号 + 实测混样比表"两列数据一起复制粘贴进去，点「识别填入」，系统会自动把比表值填到对应炉号里，填完自动关闭。示例数据长这样：

```
1   3.1
2   3.6
3   4.1
```

### 清空（整表）与单条重置
- **整表清空**：点底部「清空」按钮，只清空炉台表里的数据（产量/风量/松装/比表），**日期、班次、当班人员都不会动**。
- **单条重置**：如果只想清掉某一个炉号的数据，直接点那一行最左边的**蓝色炉号**（比如"2#"），炉号会变灰，同时这一行的产量/风量/松装/比表一起清空。
- **重新启用**：灰色炉号想重新启用有两种办法：① 再点一下炉号本身，变回蓝色；② 直接在该行的任意一个输入框里**输入一个数值**，炉号会自动变蓝、重新启用。

小提示：炉号是蓝色 = 有生产（在产），灰色 = 没生产（不计入）。填了数据炉号会自动变蓝。

### 生成日报（每天最后一步）
数据填好后，点底部「生成日报」：
- 弹窗里会预览当天的完整日报。
- 点「复制文本」，整份日报就复制好了，直接粘贴发给领导即可。

复制出来的格式是这样的：

```
2026年11月1日 夜班
当班人员：亷丽霞、许来霞、刘晓燕、张春燕、刘淑会、岳静、许娜娜（共7人）

1号 炉：产量280kg
3号 炉：产量350kg，风量18，比表3.2
```

## 二、历史页（看以前的）

点左上角菜单 →「历史」进入。默认显示当天。

- 顶部点日期可以弹日历选日期（有记录的日期会有标记点）。
- 有「前一天 / 今天 / 后一天」三个按钮翻看。
- 每次在日志页点「生成日报」，数据会自动同步到这里存一份，按"日期 + 班次"分开，同一天同班次再生成会覆盖。

---

## 三、排班页（排轮班）

点菜单 →「排班」进入，蓝色页面。

- 按"白班 → 夜班 → 休息"三天一循环自动排好，一直排到 2027 年 5 月 1 日。
- 今天的日期会用蓝色实心圈高亮。
- 想改某个人的班：点日期 → 点班次（白班/夜班/休），光标会自动跳到下一天，连续点就行。

---

## 四、配置页（设置人员和炉号）

点菜单 →「配置」进入。这里只做一次设置，之后不用常来。

### 人员配置
- 显示一个个名字小方块，右上角 × 是删除，末尾 ＋ 是新增。
- 增删后，日志页的"当班人员"会自动跟着变。

### 炉号配置
- 同样式：× 删除、＋ 新增。
- 炉号只能填纯数字，会自动去重、按从小到大排好。

---

## 五、数据说明（重要）

- 所有数据都保存在**你自己这台手机的浏览器里**，不上传任何服务器，别人看不到。
- 换手机、清浏览器数据会导致数据丢失。建议偶尔用菜单里的「导出备份」存一份到微信收藏或网盘，换设备时「导入备份」恢复。
- 这个系统目前是"单机版"：每台手机各记各的。如果以后想让几台手机数据互通，需要再升级（加云端存储和账号），目前先按单机用。
